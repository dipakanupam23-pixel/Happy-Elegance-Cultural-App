Happy Elegance PWA upload package

Upload every file in this folder to the root of repository dipakanupam23-pixel/Happy-Elegance-Cultural-App.

Files: index.html (full-screen mobile Apps Script launcher using ?mobile=1), manifest.json, service-worker.js (caches static assets only; app requires internet), icon-192.png, icon-512.png, apple-touch-icon.png.

Enable GitHub Pages for branch main and folder /(root). Expected URL: https://dipakanupam23-pixel.github.io/Happy-Elegance-Cultural-App/

iPhone: open the Pages URL in Safari > Share > Add to Home Screen. Android: Chrome menu > Install app / Add to Home screen.
